# 스토리·프로필 정리와 닉네임

## 왜

스토리(/comics, 내 4컷 전체)와 프로필(/@아이디, 게시한 4컷 격자)에 게시한 4컷이 똑같이 두 번 나왔다. 공유하는 주소(/@아이디)를 열면 프로필이 보여서 "내 4컷 보러 와"라는 뜻이 흐렸고, 화면에는 GitHub·Google 아이디만 보였다.

## 화면 역할

| 화면   | 주소                   | 보이는 것                                                                                                                                                                                                                 |
| ------ | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 피드   | `/`                    | 모두의 공개 4컷                                                                                                                                                                                                           |
| 스토리 | `/@아이디` (공유 주소) | 한 사람의 4컷. 다른 사람은 보는 사람 기준으로 공개된 게시물만 본다. 주인은 전체·공개(게시함)·비공개(게시 안 함) 탭과 주소 복사                                                                                            |
| 프로필 | `/@아이디/profile`     | 소개 카드(아바타, 닉네임, @아이디, 가입일), 숫자 칸(게시물·좋아요·팔로워·팔로잉, 주인은 만든 4컷·게시 안 함 더함), 팔로우, 스토리 링크. 주인은 닉네임 바꾸기와 계정(RSS 구독, 개인 토큰, 로그아웃, 탈퇴). 4컷 격자는 없다 |

- 메뉴의 스토리(`/comics`)는 내 `/@아이디`로, 프로필(`/me`)은 내 `/@아이디/profile`로 보낸다. 예전 주소 `/users/ID`는 그대로 `/@아이디`로 보낸다.
- 두 주소 모두 로그인 없이 열린다(`lib/auth-gate.ts`).
- 반응형: 스토리 격자는 2열(휴대폰)에서 4열(PC)까지, 머리 버튼은 좁으면 줄을 바꾼다. 프로필은 PC에서 왼쪽 소개 카드 + 오른쪽 내용 2단, 휴대폰은 1단.

## 닉네임(표시 이름)

- auth-service `users.display_name`(NULL 허용). `PATCH /api/v1/me {"displayName": "..."}`로 바꾼다. 앞뒤 공백을 지우고 20자 이하, 제어 문자 불가. 비우거나 null이면 지운다. 다른 사람과 겹쳐도 된다.
- 응답(`/me`, `/users/{id}`, `/users/lookup`, `/users?ids=`)에 `displayName`이 있으면 온다.
- 화면에 보이는 이름은 `displayName(user)` = 닉네임, 없으면 로그인 아이디(`nickname`). 주소는 언제나 로그인 아이디(`/@아이디`)다.

## 스토리 탭 API

- content-service `GET /api/v1/comics?state=IN_INBOX|POSTED`. 비우면 전체. 커서 쪽 넘김이 탭마다 정확하도록 서버에서 거른다.
